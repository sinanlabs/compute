## 可复现检查

在 Compute 仓库根目录执行：

```sh
python3 -m unittest discover -s site -p test_rank_seo.py -v
python3 site/verify_rank_seo.py --output /绝对路径/尚不存在的验收目录
```

验收脚本拒绝覆盖已存在的目录，生成 `verification.json`、`build.log` 与独立 `dist/`。只使用已有公开导出，不运行采集、探针、URL 提交或部署。

现有发布流程下，页面构建和英文镜像生成后应先检查四个榜单 URL 及它们引用的两张图片，再确认发布成功。不能只检查 HTML 返回 200。
