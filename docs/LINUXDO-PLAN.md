# linux.do 运营与信源计划（2026-09-06）

## 定位
linux.do 是中转站用户与站长最集中的社区，对我们有两个用途：**信源**（新站、价格、口碑最早出现在这里）与**分发**（司南榜、检测结果、自测工具）。
原则不变：只发测量结果，不做推荐，不贬低任何站，措辞过 `core/wording` 自检；帖子由数据自动生成，Eric 只复制粘贴。

## 一、发帖内容（自动生成，每晚随流水线产出）
每晚 03:00 生成 `data/posts/today.md`（含【标题】【正文】），并邮件发到管理员邮箱，主题「今日发帖稿」。

| 节奏 | 类型 | 内容 | 生成条件 |
|---|---|---|---|
| 周一 | 司南榜本期 | 12 张榜各前三、可达分布、多模态每秒实付、待核说明、永久链接 | 总是 |
| 周三 | 模型专题 | 轮换一个最新代旗舰：参考价、分布（低于成本 / 低于折扣 / 说得通 / 高于）、说得通区间最低 8 家（关闭注册的不列） | 该模型 ≥15 家在卖 |
| 周五 | 检测周报 | 可达分布、一致性探针计数、能力抽样、自测入口、待核 | 总是 |
| 每天 | 价格日报 | 主流模型变价表、新收录、7 天未连通 | 变价 ≥5 条或有新收录 |
| 一次 | 自测工具 | /check 怎么用、为什么比 token 计数 | 手动 `python3 site/linuxdo_post.py check` |

手动生成任一类型：`python3 site/linuxdo_post.py rank|model|probe|daily|check|all`。

## 二、发帖节奏与账号养成（Eric 操作）
1. **前两周先少发**：Discourse 新账号（信任等级 0/1）有每日发帖与外链数量限制，先浏览、回帖、点赞，进入等级 1（默认阅读 30 分钟 / 5 个主题 / 30 帖）再开始发主题帖。
2. **分类**：先看清版规，选与「AI / 资源 / 中转」相关的分类；同一类型帖子固定发一个分类，便于读者形成预期。
3. **频率上限**：每天最多 1 篇主题帖；司南榜周一、模型专题周三、检测周报周五；价格日报只在变动多的日子发，宁缺毋滥。
4. **回帖比发帖重要**：有人报价格对不上，当天核对回复（我们的核查机制会给出结论）；这是最有效的信任积累。
5. **不做的事**：不在别人的帖子里推广、不贴推广参数、不评价任何站"靠谱 / 不靠谱"、不用"降智 / 假模型 / 套壳"这类词（措辞自检会拦）。

## 三、信源（自动，需要一次配置）
`discovery/linuxdo.py` 每晚用登录 Cookie 读搜索与最新帖的公开 JSON，从正文抽域名，面板确认后入池。只读不写。

配置（一次，Cookie 失效再刷）：浏览器登录 linux.do → 开发者工具 → Application → Cookies → 复制 `_t` 与 `cf_clearance` 两个值，写到 `data/secrets.env`：
```
LINUXDO_COOKIE=_t=……; cf_clearance=……
LINUXDO_UA=（浏览器 User-Agent，地址栏输入 about:version 或在 whatismybrowser 查）
```
说明：`cf_clearance` 绑定 IP 与 UA，流水线与浏览器在同一台电脑上才有效；失效时脚本只打印一行提示、不会重试冲撞。

## 四、指标
- 信源：每周从 linux.do 新确认的站数（写在核查日报里）
- 分发：每篇帖子的回帖数、指出价格错误的回帖数（转化成核查修正条数）
- 站内：从 linux.do 来的访问与自测次数（Cloudflare Analytics 来源）
