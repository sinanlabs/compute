# 司南 Token 价格指数 · 治理规则（v1，2026-09-16 起）

这份文件回答一个问题：为什么可以把这个指数写进合同、报告和政策里。答案是四个字：规则先定。下面每一条都是对外承诺，改动本身也要按这里的流程走。

## 1. 指数是什么

- **标的**：中国模型 API 中转市场里，主流大模型每百万输出 token 的实付价格。实付 = 面板名义价 × 充值比例 ÷ 汇率（USD/CNY 取当日中间价）。
- **三个数**：折价率（市场中位实付 ÷ 官方参考价，快照）、市场中位价（美元与人民币）、点位（以 2026-09-02 = 100，按相邻两日共有模型中位价环比的几何平均链式相乘，不受模型进出影响）。
- **三档**：旗舰（官方价 ≥ $20/M）、中档（$2–20/M）、快速（< $2/M）；全市场取各模型的中位数。
- **样本门槛**：一个模型当日至少 15 个站有有效报价才进指数；一个站的报价要连续两次抓取一致才算变价；进入"待核"的报价不参与。

## 2. 发布节律与永久性

- **每日**：北京时间 05:00 前更新前一日数据（流水线 03:00 开始）。若当日流水线失败，页面保留上一日并标注日期，不补插值。
- **每周一**：司南榜出刊，窗口为上周一至周日。**每月 1 日**：上月月报定稿。
- **永久链接**：/price-index.json 全序列；/rank/<期号>；/report/<月份>。已发布的期号与 JSON 不再改动；如需修正，追加修正记录并同时保留原值。

## 3. 变更流程

- **口径变更**（分档阈值、样本门槛、链式方法、参考价来源）：先在本页与月报公告，**30 天**后生效；生效后旧口径与新口径并行发布 **90 天**，JSON 里以 `version` 字段区分。
- **字段变更**：只增不删、不改名、不改含义。
- **参考价来源变更**（如厂商改价、换更低的公开渠道价）：当日生效，在当日快照里记录来源与生效时间，不追溯改历史。
- 所有变更记录在 `docs/METHOD.md` 版本记录与 /corrections 修正日志。

## 4. 异常处理

- **我方故障**：同一探测轮里全市场可达率低于 50% 视为我方网络故障，该轮不计入任何站的可达率；已发生的一次（2026-09-11 18 时至 12 日 2 时）已剔除并公示。
- **数据核查**：字段漂移、单位提示、价格孤点、榜首差距四项自动核查，命中即"待核"，不进比对与榜单，放行留记录。
- **用户报错**：任何人可对任何数字报错；核实后署名记入修正日志。

## 5. 利益冲突

- 不接受任何被测渠道（中转站）的付费收录、付费核验、付费排位或广告；出站链接不带推广参数、不拿返佣。
- 若未来向模型厂商或金融机构提供付费数据服务，将在本页披露客户类别；付费不改变任何测量口径、样本或排序。
- 团队成员不持有任何中转站的股权或收益分成。
